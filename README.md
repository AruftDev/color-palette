# 🎨 Color Palette Generator (Coolors clone)

¡Bienvenido! Este es un generador de paletas de color  interactivo que cree  para poner a prueba mis habilidades.

## 🔧 Tecnologías utilizadas

- **HTML/CSS:** Estructura y estilos de la aplicación.
- **JS:** Manipulación del DOM, eventos de teclado.

## 🧠 Lo que aprendí 

- Control y manipulacion del DOM
- Escucha de eventos del teclado
